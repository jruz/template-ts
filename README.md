# template-ts

A TypeScript template with Oxlint, Oxfmt, Knip, sandboxed pnpm and Bun scripts.

## Create a project

Run inside your empty project folder:

```sh
gh repo create jruz/PROJECT --template jruz/template-ts --private
gh repo clone jruz/PROJECT .
template-sync init
```
